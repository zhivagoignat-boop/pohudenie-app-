# 📷 Сервис оценки КБЖУ по фото

> Это **необязательно**. Без него приложение уже умеет считать еду по фото через
> чат с Клодом: отправляешь снимок в чат, он отвечает строками, ты вставляешь их
> в блок «Еда по фото». Бесплатно и без настройки. Сервис из этой папки нужен
> только чтобы убрать копирование и считать прямо в приложении.

Приложение статическое и лежит в публичном репозитории, поэтому ключ Claude API
в него класть нельзя — его увидит любой, кто откроет исходники, и будет тратить
ваши деньги. Ключ хранится здесь, в маленьком сервисе-посреднике: приложение
отправляет ему фотографию, он спрашивает Claude и возвращает КБЖУ.

Развёртывание — 5–10 минут, платить нужно только за запросы к Claude.

---

## Что понадобится

* Аккаунт Cloudflare (бесплатный тариф: 100 000 запросов в день — с запасом).
* Ключ Claude API: https://console.anthropic.com → **API Keys** → **Create Key**.
  Пополнить баланс нужно отдельно, в разделе **Billing**.

## Сколько это стоит

Одна фотография — примерно 1500 входных токенов и 400 выходных. На модели
`claude-opus-5` ($5 за миллион входных, $25 за миллион выходных) это около
**$0.018 за снимок**, то есть меньше двух центов. Три фотографии в день —
примерно $1.6 в месяц.

Хочется дешевле — в файле `photo-kbju.js` поменяйте строку `const MODEL` на
`claude-sonnet-5` (вчетверо дешевле) или `claude-haiku-4-5` (ещё дешевле).
Оценка порций у моделей послабее менее точная, но для дневника обычно хватает.

## Развёртывание

1. Откройте https://dash.cloudflare.com → **Workers & Pages** → **Create** →
   **Start with Hello World!** → **Deploy**.
2. Назовите воркер, например `kbju`.
3. Нажмите **Edit code**, удалите содержимое редактора и вставьте туда целиком
   файл [`photo-kbju.js`](photo-kbju.js). **Deploy**.
4. Вернитесь в воркер → **Settings** → **Variables and Secrets** и добавьте:

   | Имя | Тип | Значение |
   |---|---|---|
   | `ANTHROPIC_API_KEY` | **Secret** | ваш ключ `sk-ant-…` |
   | `ALLOWED_ORIGIN` | Text | `https://zhivagoignat-boop.github.io` |
   | `ACCESS_TOKEN` | **Secret** | любой пароль, например `myfood2026` (необязательно, но лучше задать) |

   `ALLOWED_ORIGIN` — это адрес приложения без пути. Без него браузер
   заблокирует запрос. `ACCESS_TOKEN` не даёт посторонним тратить ваш баланс,
   если кто-то узнает адрес воркера.

5. Нажмите **Deploy** ещё раз, чтобы переменные подхватились.
6. Скопируйте адрес воркера — он выглядит как
   `https://kbju.ваш-логин.workers.dev`.

## Подключение к приложению

В приложении: **Прогресс → 📷 Оценка по фото** → вставьте адрес воркера и,
если задавали, пароль. После этого в разделе **Еда** появится кнопка
«Оценить по фото».

## Проверка

```bash
curl -X POST https://kbju.ваш-логин.workers.dev \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer myfood2026" \
  -d "{\"image\":\"$(base64 -w0 фото.jpg)\",\"media_type\":\"image/jpeg\"}"
```

Ответ — JSON с полем `items`: список блюд с калориями, белком, жиром,
углеводами и клетчаткой.

## Если что-то не работает

| Ответ | Причина |
|---|---|
| `401 Неверный пароль` | В приложении не вписан или не совпадает `ACCESS_TOKEN` |
| `500 На сервисе не задан ANTHROPIC_API_KEY` | Переменная не добавлена или воркер не передеплоен после её добавления |
| Ошибка CORS в браузере | `ALLOWED_ORIGIN` не совпадает с адресом приложения (протокол и домен, без пути) |
| `502 Claude API вернул 401` | Ключ неверный или отозван |
| `502 Claude API вернул 400 credit balance` | На балансе Anthropic нет денег |

## Насколько можно доверять цифрам

Это оценка по внешнему виду. Модель не знает, сколько масла ушло на сковороду
и сколько сахара в соусе, поэтому в ресторанной еде реальные калории обычно
выше видимых. Для дневника этого достаточно: важен порядок величины и
постоянство подхода, а не точность до килокалории. Если знаете состав точнее —
поправьте вручную в разделе «Своё / добор».
