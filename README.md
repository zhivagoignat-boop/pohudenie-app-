# 💪 Похудение — Telegram Mini App

Личный трекер по программе «тренировки + питание + прогресс», сделанный как
[Telegram Mini App](https://core.telegram.org/bots/webapps). Открывается внутри Telegram,
подстраивается под его тему и синхронизирует данные через облако Telegram.

**Ни серверов, ни аналитики, ни аккаунтов.** Личные данные (вес, рост, возраст, даты, отметки)
задаются в самом приложении при первом запуске и хранятся только на устройстве пользователя
и в его личном облаке Telegram. В этом репозитории их нет.

## Что внутри

| Вкладка | Содержимое |
|---|---|
| 🏠 Сегодня | Вес и отклонение от плановой кривой, калории и белок, шаги, сон, вода, состояние плеча, чеклист подготовки |
| 🏋️ Тренировка | 4 тренировочных дня, отметки по упражнениям, рабочие веса с историей, техника, таймер отдыха, кардио |
| 🍽️ Еда | Приёмы пищи с КБЖУ и клетчаткой, добор клетчатки (база продуктов и готовые наборы), оценка КБЖУ по фото, блюда кафе, список покупок |
| 📈 Прогресс | Взвешивания и талия, график факт/план, силовая прогрессия, фото по неделям, профиль, экспорт данных |
| ⏰ График | Неделя целиком и распорядок дня |
| 🚨 Плечо | Три критичных упражнения для ротаторной манжеты со статусом, запрещённые движения, дневник боли |
| 🤖 Отчёт | Автоматический markdown-отчёт о прогрессе — копируется в чат одной кнопкой |

## Запуск

Статическая страница, сборка не нужна.

```bash
python3 -m http.server 8000   # затем http://localhost:8000
```

Для Telegram: выложить содержимое репозитория на любой HTTPS-хостинг
(здесь настроен GitHub Pages) и указать адрес в @BotFather —
`/mybots` → бот → Bot Settings → Menu Button.

## Структура

```
index.html            интерфейс
assets/css/app.css    стили (светлая/тёмная тема + тема Telegram)
assets/js/data.js     программа: упражнения, питание, расписание, правила безопасности
assets/js/store.js    состояние в localStorage, профиль, даты, расчёты
assets/js/report.js   генератор отчёта
assets/js/telegram.js Telegram Mini App: тема, кнопки, облачная синхронизация
assets/js/ui.js       рендер вкладок
sw.js                 офлайн-режим
worker/               необязательный сервис оценки КБЖУ по фото
```

## Еда по фото

Три пути, от простого к автоматическому:

1. **Через чат с Клодом** — отправить снимок, получить строки
   `Блюдо | ккал | белок | жир | углеводы | клетчатка` и вставить их
   в приложение. Ничего настраивать не нужно.
2. **На глаз** — встроенная таблица оценки порций по руке.
3. **Автоматически** — свой сервис-посредник с ключом Claude API
   (папка `worker/`): ключ нельзя класть в статическое приложение,
   его увидит любой, поэтому он живёт в отдельном воркере.

## Безопасность плеча

Программа рассчитана на человека с вывихом плеча в анамнезе: жимы только в машине,
никаких боковых подъёмов и тяг за голову, обязательные Face Pulls и обратный Pec Deck.
Приложение отдельно следит, чтобы эти упражнения не пропускались.

Это не медицинская рекомендация — при боли в плече нужен врач, а не приложение.
